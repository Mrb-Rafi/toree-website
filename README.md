# Toree

Static website for **Toree**: cotton canvas bags that carry the stories of Bangladesh.

- `index.html`: home page with the three story teasers
- `stories/`: one page per design (Hara Shoshir Hara Hashi, Bidrohi Prokritikonna, Abar Jigay)
- `assets/`: styles, script, logos and web-optimised images

Plain HTML, CSS and a little JavaScript. No build step or database is needed to serve it. Open `index.html`, or serve the folder with any static host (for example GitHub Pages).
